# Симулятор маркетолога — карьерный режим (MVP)

Трипваер-продукт: карьерный симулятор для маркетологов в стиле карьерного режима FIFA.
Игрок начинает джуном, выполняет миссии, набирает XP и растёт до CMO. Источник данных —
[карта экспертности](docs/full-stack-marketing-karta-ekspertnosti.md).

## Что внутри

Один хаб-дашборд с 5 зонами:

1. **Профиль маркетолога** — карточка игрока: роль, XP-бар, статы по 8 разделам аудита, регалии
2. **Календарь сезона** — миссии с дедлайнами и статусами (предстоит / в работе / выполнено / просрочено)
3. **Карьерная лестница** — Junior → Контент/Перформанс (развилка) → Senior → CMO
4. **База знаний** — 8 модулей + 2 бонуса; модули выше текущей роли заблокированы
5. **Чат с AI-наставником** — наставник-CMO через Anthropic API: даёт задания, отвечает, оценивает

Прогресс хранится в `localStorage`. Миссия «Найди узкое горлышко» — заглушка со статусом «скоро».

## Стек

- Frontend: React + Vite + TypeScript + Tailwind CSS, иконки `lucide-react`
- AI-прокси: Node + Express + официальный SDK `@anthropic-ai/sdk` (ключ остаётся на сервере)

## Запуск

```bash
# 1. Зависимости
npm install

# 2. Ключ и модель
cp .env.example .env
# открой .env и подставь:
#   ANTHROPIC_API_KEY=sk-ant-...   (ключ из console.anthropic.com)
#   ANTHROPIC_MODEL=...            (актуальную строку модели возьми из docs.claude.com)

# 3. Запуск фронта и прокси одной командой
npm run dev
```

- Фронт: http://localhost:5173 (Vite проксирует `/api` на прокси)
- AI-прокси: http://localhost:3001

Раздельный запуск: `npm run dev:web` (фронт) и `npm run dev:api` (прокси).

Без `ANTHROPIC_API_KEY` дашборд работает полностью, не работает только чат с наставником.
