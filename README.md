# MarketSim — маркетологтарға арналған жұмыс симуляторы 🚀

Duolingo стиліндегі интерактивті симулятор: тіркелген пайдаланушы кәсіп сферасын таңдап, виртуалды компанияда junior-маркетолог ретінде жұмыс істей бастайды.

## Мүмкіндіктер

- **Тіркелу / кіру** — жеке аккаунт (деректер браузердің localStorage-ында сақталады)
- **Кәсіп сферасын таңдау** — E-commerce, EdTech, HoReCa, Fitness (әрқайсысында өз компаниясы мен легендасы)
- **Ассистент-чат onboarding** — наставник Аружан жобамен таныстырып, жұмысқа кіргізеді
- **Задачалар жолы (Duolingo-стилі)** — performance marketing және content marketing бойынша 10 интерактивті задача, ретімен ашылады
- **Подсказка бөлімі** — әр задачада қалай орындау керегі туралы кеңестер + байланысты сабаққа сілтеме
- **Курс (FMS бағдарламасы)** — 5 модуль, 13 сабақ: маркетинг негіздері, content marketing, performance marketing, аналитика, стратегия. Әр сабақта квиз бар
- **Жеке кабинет (Дэшборд)** — XP, деңгей, streak, скиллдер прогресі, апталық белсенділік
- **Канбан** — задачаларды Backlog → In Progress → Review → Done бағандарында сүйреу
- **Календарь** — задача дедлайндары ай көрінісінде
- **Гант чарт** — барлық задачалардың уақыт сызығы

## Іске қосу

```bash
npm install
npm run dev      # әзірлеу режимі (http://localhost:5173)
npm run build    # өндірістік сборка (dist/)
npm run preview  # сборканы локальді көру
```

## Технологиялар

- React 18 + TypeScript
- Vite
- React Router (HashRouter — статикалық хостингке ыңғайлы)
- Backend жоқ: барлық прогресс localStorage-та
